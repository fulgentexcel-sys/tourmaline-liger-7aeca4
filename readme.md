# Lakshya School ERP — A to Z Clickable Frontend

## Included
- Institute dashboard with animated sidebar and cards
- Classes, departments, subjects, time slots
- Students, teachers, important figures, staff
- Routine creation and routine view
- Fees, receipts and QR verification demo
- Admit cards
- Marksheets / results
- Transfer Certificates
- Bonafide / Character / Migration certificate demo
- Notes, notifications, live meetings
- Attendance
- Library, transport, hostel
- Expenses and HR
- Reports & analytics
- Roles & permissions
- Audit logs
- School settings
- Public school website preview
- Search, filters, CSV export, print
- Add/view/delete demo records
- LocalStorage persistence
- Responsive mobile layout
- Document preview and print layouts inspired by the supplied reference image

## Run
Open `index.html` in a modern browser.

No server is required for the demo.

## Important
This ZIP is a frontend/demo prototype. Payment gateway, SMS/WhatsApp, Firebase, real database, authentication, QR verification backend, file storage, AI APIs and production security must be connected to the real Lakshya backend before production use.
